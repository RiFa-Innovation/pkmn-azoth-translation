How this guide is made

The reference sections are not typed by hand. scripts/guide_data.py reads them from the patched ROM: base stats, learnsets, evolutions, moves, items, TMs, wild tables and trainer teams. When the patch changes, rebuild the data and the guide changes with it. The story pages are written from the project's own notes and marked where they were not re-tested in play.

The original Chinese-language wiki, 宝可梦水银 百科, covers areas this guide does not yet (96 side quests, Pokémon HOME, distributions). It says its main walkthrough and gym teams are still planned, which this guide provides in English.
