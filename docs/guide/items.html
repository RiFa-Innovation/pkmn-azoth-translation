Search by item, TM move or place name. Select an item for every source the ROM shows: item balls, gifts and quest rewards, shop stock, Frontier BP prices, wild Pokémon that hold it and trainers that carry it.

How complete this is

Sources are read from the game's scripts, shop lists and held-item tables. A location appears only when it could be pinned to one or two maps, so some gifts say “location not determined”. Items given by the game's native code, or handed out by scripts that pick the item at run time, are not listed. Map names are the game's own area names, with the map id in brackets where floors share a name; a few hack maps reuse a vanilla name.
